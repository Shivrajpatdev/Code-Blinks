# Code Blinks Website

A simple responsive six-page static website for Code Blinks.

Pages:
- index.html — Home
- vision.html — Vision & Overview
- impact.html — Impact
- about.html — About Us
- program.html — Our Program
- contact.html — Contact Us

Assets:
- assets/logo.png
- assets/hero-banner.png
- assets/founder.png

The Contact page links to the provided Google Form.
No build tools or frameworks are required. Open index.html in a browser or upload the folder to a static hosting service.
